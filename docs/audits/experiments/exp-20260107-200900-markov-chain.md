## Algorithm
**Name:** Markov Chain for Comment Pattern Detection
**Expected complexity:** O(n) build, O(1) transition lookup, O(k) generation
**Required operations:**
- `train(sequences: List[List[str]])` - Learn from tokenized comments
- `probability(from_word: str, to_word: str) -> float` - Get transition probability
- `generate(start: str, length: int) -> List[str]` - Generate comment-like text
- `likely_patterns(word: str) -> List[Tuple[str, float]]` - Get likely next words

## Codebase Application

**Problem:** Misleading comments often follow patterns:
- "will be" → "implemented" / "handled" / "fixed" (speculation)
- "See:" → path → (but path might not exist)
- "FUTURE:" → promises that may never happen

By training a Markov chain on comment text, we can:
1. Detect suspicious patterns (high-probability misleading sequences)
2. Generate example misleading comments for testing
3. Score new comments by how "misleading-like" they are

**Use Case:** Given a new comment, check if it follows misleading patterns.

## Hypothesis
**I expect:** The agent will implement a basic Markov chain correctly
**Because:** First-order Markov chains are simple (count and normalize). The comment pattern context makes it practical.
