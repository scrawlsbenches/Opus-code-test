Key insight for MinHash:
    If you pick a random hash function h, then:
    P(min(h(A)) == min(h(B))) = J(A, B) = |A ∩ B| / |A ∪ B|

Key insight for banding:
    Divide signature into b bands of r rows each.
    Two docs are candidates if they match in at least one band.
    P(candidate) ≈ 1 - (1 - s^r)^b where s = true similarity
