## Algorithm
**Name:** Union-Find (Disjoint Set Union)
**Expected complexity:** O(α(n)) per operation with path compression and union by rank (effectively O(1))
**Required operations:**
- `make_set(x)` - Create a new set containing only x
- `find(x) -> root` - Find the representative of x's set
- `union(x, y)` - Merge the sets containing x and y
- `connected(x, y) -> bool` - Check if x and y are in the same set

## Hypothesis
**I expect:** The agent will implement basic union-find but may forget path compression or union by rank
**Because:** The basic algorithm is simple, but the optimizations that make it O(α(n)) are often omitted.
