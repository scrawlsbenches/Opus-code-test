## Algorithm
**Name:** DAG for GoT Task Dependencies
**Expected complexity:** O(V + E) for most operations
**Required operations:**
- `add_task(task_id: str)` - Add a task node
- `add_dependency(from_task: str, to_task: str)` - Add dependency edge
- `topological_sort() -> List[str]` - Get tasks in dependency order
- `blocked_by(task_id: str) -> Set[str]` - Get all blocking tasks
- `blocks(task_id: str) -> Set[str]` - Get all tasks this blocks

## Codebase Application

**Problem:** The GoT (Graph of Thought) system tracks tasks with dependencies. We need a DAG to:
- Prevent circular dependencies (T-001 depends on T-002 depends on T-001)
- Find execution order (topological sort)
- Query blocking relationships

**Use Case:** When creating task dependencies in GoT, validate no cycles exist.

**Reference:** See `cortical/got/` for existing task management. The `got_utils.py` supports `edge add FROM_ID TO_ID DEPENDS_ON`.
