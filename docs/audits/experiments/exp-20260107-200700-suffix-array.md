# Experiment: exp-20260107-200700-suffix-array

## Algorithm
**Name:** Suffix Array for Comment Pattern Mining
**Expected complexity:** O(n log n) or O(n log² n) build, O(m log n) search
**Required operations:**
- `build(text: str)` - Construct suffix array from text
- `search(pattern: str) -> List[int]` - Find all occurrences of pattern
- `lcp_array() -> List[int]` - Compute Longest Common Prefix array
- `repeated_substrings(min_length: int) -> List[str]` - Find repeated patterns

## Codebase Application

**Problem:** We want to find repeated patterns in comment text across the codebase:
- Repeated phrases like "will be implemented" appearing in multiple comments
- Common boilerplate that might be copy-pasted misleading text
- Repeated references to non-existent files

The LCP array helps find the longest repeated substrings efficiently.

**Use Case:** Given all comment text concatenated, find patterns that appear multiple times (suggesting copy-pasted misleading comments).

**Reference:** This complements the Inverted Index (word-level search) by enabling substring-level pattern discovery.

## Hypothesis
**I expect:** The agent will implement basic suffix array but struggle with efficient construction or LCP
**Because:** Naive O(n² log n) construction is easy, but O(n log n) requires understanding of suffix comparison tricks. LCP array is often implemented incorrectly.
